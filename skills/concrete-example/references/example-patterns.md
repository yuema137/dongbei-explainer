# Example patterns

- Version control: ASCII commit graph and hash identity.
- Async systems: one queue, two callbacks, and a timeline.
- Containers: one immutable image and two runtime container states.
- GPU behavior: a short time slice separating allocated bytes from active kernels.
- ML training: tiny batch counts and explicit optimizer-step timing.
- Statistics: a small hypothetical sample plus the actual conditioning statement.
- Regression exposure: two observations with different hours and the equation containing `log(exposure)`.

If a diagram already is the domain's natural representation, do not replace it with trains, kitchens, warehouses, or uncles.
