# Contributing

The most useful contributions are technically checked explanation cases, terminology annotations, and dialect corrections from identified regional/reader perspectives.

For a case, include audience, required mechanism, common misconception, detail that simplification must preserve, and jargon needing a familiarity decision. Do not submit one “golden” wording as the test.

For language guidance, distinguish “I understand it” from “it reads naturally in a serious technical explanation.” Cite linguistic or corpus evidence when making general claims. Personal language judgment is welcome when labeled as such.

Run `scripts/validate`, the standard quick validator for every skill, and `scripts/lint_text` on new Dongbei samples. Keep canonical behavior under `skills/`; never hand-edit generated host installation directories.
