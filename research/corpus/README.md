# 表演语料怎么用

这里记录小品、访谈等口语材料带来的结构观察，不保存大段原文。

这类材料能告诉我们一句话怎么起、怎么追问、怎么把抽象东西落到具体场景。它不能直接决定哪些词可以输出。作品要逗观众，会故意夸张口音、制造误解、损人或重复口头禅，这些效果跟技术解释要的清楚、准确、尊重不是一回事。

优先级固定如下：

1. 产品负责人的普通话用户标注边界；
2. 技术准确性和读者能否立刻理解；
3. 语料提供的话语结构；
4. 单个词在作品里出现过多少次。

换句话说，语料只能给结构加证据，不能把“排除”或“高风险”的词翻成“可用”。后续每加入一份材料，都按同一个格式记录：可迁移结构、只能用于表演的手法、对技术解释的具体影响、是否触碰既有边界。

完整台词通常受版权保护，不提交到 MIT 仓库。这里只保留来源信息、分析结果和为说明结构所需的少量短句。
